# jcbrand

Sistema de diseño de la marca de JC (José Carlos Martínez), la de jcmartinez.net. Este repo es el paquete privado `@jcmartinezma/jcbrand` y, a la vez, la skill de Cursor que explica cómo usarlo.

Hoy el paquete publica **tokens** y **fuentes**. Los componentes de UI vendrán después, en React. Un proyecto Astro (el portfolio, por ejemplo) puede montarlos como islas. Esta Storybook es la referencia visual: se abre en local y no se publica.

## Instalar el paquete

El paquete vive en GitHub Packages, no en npmjs.com. En el proyecto que lo consume, un `.npmrc` en la raíz (sí se puede commitear: el token no va escrito):

```
@jcmartinezma:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=${GITHUB_TOKEN}
```

`GITHUB_TOKEN` es una variable de entorno. Su valor es un personal access token **classic** con `read:packages` y `repo`. No lo pegues en el repo, ni en el `.npmrc`, ni en el código.

```bash
export GITHUB_TOKEN="el PAT classic"
npm install @jcmartinezma/jcbrand
```

## Importar fuentes y tokens

En el entry global del proyecto, primero las fuentes y después los tokens:

```js
import "@jcmartinezma/jcbrand/fonts.css";
import "@jcmartinezma/jcbrand/dist/css/tokens.css";
```

Las fuentes son Rethink Sans e IBM Plex Mono. Los tokens son custom properties. En un componente se usa el nombre semántico (`--color-bg-primary`), no el primitivo (`--gray-800`).

## Tema

Oscuro es el de siempre: no hace falta atributo, porque `:root` ya es el tema oscuro. El claro es opt-in:

```html
<html lang="es" data-theme="light">
```

El interruptor **Tema** de esta barra hace lo mismo sobre la vista y sobre estas páginas. Oscuro es el valor inicial.

## Qué hay en Foundations

Cada página lee `tokens/` al arrancar. Si un JSON cambia y se vuelve a construir `dist/`, la muestra cambia con él. No hay una segunda lista de hex escrita a mano.

- Color: paletas primitivas y colores semánticos, en oscuro y en claro.
- Tipografía: familias, tamaños, pesos, interlineado y tracking, con una muestra viva.
- Espaciado, radio, sombra, motion, desenfoque y opacidad.
- Contraste: una historia para el panel Accessibility. No modifica los tokens.
