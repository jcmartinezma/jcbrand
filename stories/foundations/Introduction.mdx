# jcbrand

Sistema de diseño de la marca de JC (José Carlos Martínez), la de jcmartinez.net. Este repo es público: otros proyectos lo instalan como dependencia directa de GitHub (`@jcmartinezma/jcbrand`) y, a la vez, es la skill de Cursor que explica cómo usarlo.

Hoy la dependencia trae **tokens** y **fuentes**. Los componentes de UI vendrán después, en React. Un proyecto Astro (el portfolio, por ejemplo) puede montarlos como islas. Esta Storybook es la referencia visual: se abre en local y no se publica.

## Instalar la dependencia

No está en npmjs.com ni en GitHub Packages. Como el repo es público, npm lo descarga directamente de GitHub, sin `.npmrc` ni token:

```bash
npm install github:jcmartinezma/jcbrand#semver:^0.2.0
```

`#semver:^0.2.0` elige el tag de git más alto del rango (`v0.2.x`). Para fijar una versión exacta, `#v0.2.0`. No lo instales sin `#`: tomaría la rama `main`, sin versión.

## Importar fuentes y tokens

En el entry global del proyecto, primero las fuentes y después los tokens:

```js
import "@jcmartinezma/jcbrand/fonts.css";
import "@jcmartinezma/jcbrand/dist/css/tokens.css";
```

Las fuentes son Rethink Sans e IBM Plex Mono. Los tokens son custom properties. En un componente se usa el nombre semántico (`--color-bg-primary`), no el primitivo (`--color-gray-800`).

## Tema

Oscuro es el de siempre: no hace falta atributo, porque `:root` ya es el tema oscuro. El claro es opt-in:

```html
<html lang="es" data-theme="light">
```

El interruptor **Tema** de esta barra hace lo mismo sobre la vista y sobre estas páginas. Oscuro es el valor inicial.

## Qué hay en Foundations

Cada página lee `tokens/` al arrancar. Si un JSON cambia y se vuelve a construir `dist/`, la muestra cambia con él. No hay una segunda lista de hex escrita a mano.

- Color: paletas primitivas y colores semánticos, en oscuro y en claro.
- Tipografía: familias, tamaños, pesos, interlineado y tracking, con una muestra viva.
- Espaciado, radio, sombra, motion, desenfoque y opacidad.
- Contraste: una historia para el panel Accessibility. No modifica los tokens.
