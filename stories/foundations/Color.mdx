# Color

Dos capas. **Core** son los primitivos (gris, rojo, verde, azul, blanco y negro). **Semantic** les pone un rol: fondo, superficie, texto, icono y borde.

El tema oscuro es el valor de `:root`. El claro solo redefine los tokens que están en el JSON de light; el resto hereda. La muestra **Activo** usa la custom property, así que el interruptor Tema la cambia. Oscuro y Claro son el hex resuelto de cada JSON, para compararlos a la vez.
