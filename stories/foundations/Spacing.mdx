# Espaciado

La barra tiene el ancho de la custom property. Si el valor es muy grande, la fila se desplaza en horizontal: el ancho no se recorta para que quepa.

En un componente se usa el nombre semántico (`--spacing-sm`), no el peldaño numérico (`--spacing-300`).
