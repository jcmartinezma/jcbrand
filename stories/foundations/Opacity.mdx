# Opacidad

Solo existe como primitivo. No hay capa semántica, ni un 100%. Para un velo de modal se usa `--color-bg-overlay`, que ya lleva alpha, en lugar de inventar un token de opacidad.

El build escribe el número del JSON como porcentaje. La ficha de cada token muestra ese porcentaje.
